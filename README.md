# zhihu-novel-assistant

> 知乎盐言故事（短篇 1-3w 字 / 长篇连载 10w+ 字）AI 创作与润色 Skill：内置爆款标题公式、8 维精准标签体系、黄金 300 字开篇钩子及高密度反转叙事规范。

## 核心特性

1. **标准 8 维标签体系**：自动匹配男/女频、朝代、题材（≤2）、身份关系（0-3）、性格人设（0-2）、核心设定（0-2）、情节标签（1-3）、情绪风格（1-2）。
2. **知乎式包装与强钩子**：杜绝慢热铺垫，强制前 300 字抛出核心冲突/异常奇观，采用第一人称伪纪实口语化叙事。
3. **盐言过稿与付费卡点控制**：手机端短段落呼吸感、章末强断章悬念、每 4,000～5,000 字设置免费转付费黄金卡点。
4. **10w+ 长篇收益向架构**：支持“短篇爆款开局 + 单元规则副本 + 主线暗线闭环”的百万/十万字级连载大纲与分章输出。

## 安装与使用

### 方式一：工作区级 Skill（推荐）
将本仓库克隆或复制到项目的 `.agents/skills/zhihu-novel-assistant/` 目录下：

```bash
git clone https://github.com/MingoZhou/zhihu-novel-assistant.git .agents/skills/zhihu-novel-assistant
```

### 方式二：全局 Skill
复制到个人全局 Skills 目录（如 `~/.gemini/antigravity/skills/zhihu-novel-assistant/`）。

## 目录结构

- `SKILL.md`：Agent Skill 核心指令与标签库、叙事铁律。
- `README.md`：项目说明文档。
